# Disaster alert drafting workflow

Drafts multilingual disaster alerts from a bulletin, for a human officer to approve before sending.

## Overview

Turns an official weather or hazard bulletin into short alerts in English and Filipino, following the national alert templates. Nothing is sent without an officer's approval.

## Interfaces

Protocol: `other`. Languages: en, tl.
